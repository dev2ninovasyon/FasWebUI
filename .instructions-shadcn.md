### 1.2 Naming Conventions (FasWebUI-Specific)

**Folders:**
- Turkish domain modules: `PascalCase` (e.g., `Hesaplamalar/`, `KidemTazminatiBobi/`)
- Helper/grouping folders: `kebab-case` (e.g., `form-components/`, `grid-wrappers/`)
- Route groups: Parentheses (e.g., `(Uygulama)/`, `(auth)/`)
- shadcn/ui components: `kebab-case` in `components/ui/` (auto-generated)

**Files:**
- Components: `PascalCase` (e.g., `BelgeKontrolCard.tsx`, `PersonelBoxAutocomplete.tsx`)
- Hooks: `camelCase` starting with `use` (e.g., `useBildirim.ts`, `useFormData.ts`)
- API modules: `PascalCase` (e.g., `Hesaplamalar.ts`, `Donusum.ts`)
- Utilities: `camelCase` (e.g., `validation.ts`, `formatting.ts`)
- Types: `PascalCase` (e.g., `Hesaplamalar.types.ts`, `domain.types.ts`)
- Constants: `UPPER_SNAKE_CASE` (e.g., `API_TIMEOUT`, `MAX_FILE_SIZE`)

**Variables/Functions:**
- `camelCase` for variables, functions, and constants within files
- `PascalCase` for React components and classes

**Types/Interfaces:**
- `PascalCase` for all TypeScript types and interfaces
- Suffix with appropriate type (e.g., `KidemTazminatiBobi.types.ts` for domain types)
- Group related types in a single file per domain module

### 1.3 Module Organization Pattern

Each domain module (e.g., `Hesaplamalar`, `Donusum`) follows this pattern:

```
src/api/Hesaplamalar/
├── Hesaplamalar.ts       # Main API client with all endpoints
```

## 2. App Router Best Practices (Next.js 16+)

### 2.1 Server Components vs Client Components

**Default to Server Components** unless you need interactivity, browser APIs, or state management.

**Server Component (Default):**
```tsx
// app/(Uygulama)/Hesaplamalar/KidemTazminatiBobi/page.tsx
import { fetchKidemData } from '@/lib/calculations/kidem';

export default async function KidemTazminatiPage() {
  // ✅ Direct async/await - fetches at build/request time
  const data = await fetchKidemData();
  
  return (
    <div>
      <h1>Kidem Tazminatı Hesaplama</h1>
      {/* <KidemForm /> works if it's a Client Component */}
    </div>
  );
}
```

**Client Component (When Needed):**
```tsx
// components/KidemForm.tsx
'use client'; // ✅ Place at the top

import { useState } from 'react';
import { updateFormHazirlayanOnaylayan } from '@/api/Hesaplamalar';

export function KidemForm() {
  const [expandedSections, setExpandedSections] = useState<{ [key: string]: boolean }>({
    hazirlayan: false,
    onaylayan: false,
    kaliteKontrol: false,
  });

  const toggleSection = (section: string) => {
    setExpandedSections(prev => ({
      ...prev,
      [section]: !prev[section]
    }));
  };

  return (
    // JSX with interactivity
  );
}
```

### 2.2 Client Components in Server Components

✅ **Correct:** Import Client Component directly in Server Component

```tsx
// Server Component (app/page.tsx)
import { DashboardNav } from '@/components/DashboardNav'; // Client Component

export default async function Dashboard() {
  return (
    <div>
      <DashboardNav /> {/* Works perfectly */}
      {/* Other server content */}
    </div>
  );
}
```

❌ **Incorrect:** Never use `next/dynamic` with `{ ssr: false }` in Server Components

```tsx
// DON'T DO THIS
const DynamicNav = dynamic(() => import('@/components/DashboardNav'), { ssr: false });
```

### 2.3 Async Request APIs in Server Components

Be aware that certain APIs are async in App Router:

```tsx
// ✅ Correct: await cookies/headers
import { cookies, headers } from 'next/headers';

export default async function Page() {
  const cookieStore = await cookies();
  const headersList = await headers();
  
  const token = cookieStore.get('authToken')?.value;
  
  return <div>Authenticated: {!!token}</div>;
}
```

### 2.4 Dynamic Segments in Routes

```
app/(Uygulama)/Hesaplamalar/[yil]/[formKodu]/page.tsx
               ^^^^^^^^^^^^^^^^^^^^^^^^^^^^
               Dynamic segments
```

In Server Components, `params` may be Promises:

```tsx
// Handle both sync and async params
interface PageProps {
  params: Promise<{ yil: string; formKodu: string }>;
}

export default async function Page({ params }: PageProps) {
  const { yil, formKodu } = await params;
  // Now safely use yil and formKodu
}
```

## 3. API Layer & Data Fetching

### 3.1 apiFetch Base Client (apiBase.ts)

All API calls go through the centralized `apiFetch` wrapper:

```typescript
// src/api/apiBase.ts
import { apiFetch, url as apiBaseUrl } from "@/api/apiBase";
import SecureTokenManager from "@/utils/SecureTokenManager";

// Pattern: Use apiFetch for all HTTP requests
const response = await apiFetch(
  `/Hesaplamalar/KidemHesapla?yil=${yil}&hazirlayanId=${hazirlayanId}`,
  {
    method: "GET",
    headers: {
      accept: "application/json",
    },
  }
);

if (response.ok) {
  const data = await response.json();
  return data;
}
```

**Benefits:**
- Centralized token management via `SecureTokenManager`
- Consistent error handling
- Single point for interceptors/middleware
- Authentication header injection

### 3.2 Module-Based API Organization

Each domain module has its own API client file:

```typescript
// src/api/Hesaplamalar/Hesaplamalar.ts
import { apiFetch } from "@/api/apiBase";

export const getKidemHesapla = async (yil: number, hazirlayanId: number) => {
  const response = await apiFetch(
    `/Hesaplamalar/KidemHesapla?yil=${yil}&hazirlayanId=${hazirlayanId}`,
    { method: "GET", headers: { accept: "application/json" } }
  );
  if (response.ok) return response.json();
  throw new Error("Hesaplama başarısız");
};

export const updateFormHazirlayanOnaylayan = async (
  yil: number,
  formKodu: string,
  data: FormHazirlayanOnapprovalData
) => {
  const response = await apiFetch(
    `/Hesaplamalar/UpdateFormHazirlayanOnaylayan?yil=${yil}&formKodu=${formKodu}`,
    {
      method: "POST",
      headers: { accept: "*/*", "Content-Type": "application/json" },
      body: JSON.stringify(data),
    }
  );
  if (response.ok) return response.json();
  throw new Error("Form güncellemesi başarısız");
};

// Always export types for module consumers
export type * from "./Hesaplamalar.types";
```

### 3.4 Real-Time Communication with SignalR

FasWebUI uses SignalR for live notifications with automatic polling fallback. Use the `useBildirimConnection` hook from `@/hooks/useBildirimConnection`:

#### ✅ **Option 1: Advanced Control (Recommended)**

```typescript
import { useBildirimConnection } from "@/hooks/useBildirimConnection";
import { BildirimEvent } from "@/api/BaglantiBilgileri/BaglantiBilgileri.types";

export function NotificationCenter({ denetciId }: { denetciId: number }) {
  const { status, registerCallback, stopConnection } = useBildirimConnection({
    denetciId,
    autoConnect: true,  // Start connection immediately
    pollingInterval: 5000  // Fallback polling interval
  });

  useEffect(() => {
    // Register callback for new notifications
    const handleNewNotification = (bildirim: BildirimEvent) => {
      console.log("📌 Yeni bildirim:", bildirim.konu);
      
      // Show toast/notification
      enqueueSnackbar(bildirim.konu, {
        variant: "info",
        autoHideDuration: 5000,
      });
      
      // Update notification list
      setNotifications(prev => [bildirim, ...prev]);
    };

    registerCallback(handleNewNotification, denetciId);

    return () => {
      stopConnection();
    };
  }, [denetciId]);

  return (
    <div>
      <StatusBadge status={status} />
      {/* Render notifications */}
    </div>
  );
}
```

#### ✅ **Option 2: Simple Pattern (Quick Setup)**

```typescript
import { useSimpleBildirim } from "@/hooks/useBildirimConnection";
import { BildirimEvent } from "@/api/BaglantiBilgileri/BaglantiBilgileri.types";

  });

```

#### **Real-World Example (Notification.tsx)**

```typescript

import { getBildirimler, updateBildirimlerOkundumu } from "@/api/BaglantiBilgileri/BaglantiBilgileri";
```

## 5. State Management (Redux)

### 5.1 Redux Store Structure

```typescript
// src/store/slices/hesaplamaSlice.ts
import { createSlice, PayloadAction } from "@reduxjs/toolkit";

interface HesaplamaState {
  kidemData: KidemTazminatıData | null;
  loading: boolean;
  error: string | null;
}

const initialState: HesaplamaState = {
  kidemData: null,
  loading: false,
  error: null,
};

export const hesaplamaSlice = createSlice({
  name: "hesaplama",
  initialState,
  reducers: {
    loadKidemStart(state) {
      state.loading = true;
      state.error = null;
    },
    loadKidemSuccess(state, action: PayloadAction<KidemTazminatıData>) {
      state.kidemData = action.payload;
      state.loading = false;
    },
    loadKidemError(state, action: PayloadAction<string>) {
      state.loading = false;
      state.error = action.payload;
    },
  },
});

export const { loadKidemStart, loadKidemSuccess, loadKidemError } = hesaplamaSlice.actions;
export default hesaplamaSlice.reducer;
```

### 5.2 Using Redux in Components

**In Server Components:** Use Redux only for client-side state. Don't try to dispatch from Server Components.

**In Client Components:**
```tsx
'use client';

import { useSelector, useDispatch } from 'react-redux';
import { loadKidemStart, loadKidemSuccess, loadKidemError } from '@/store/slices/hesaplamaSlice';
import { getKidemHesapla } from '@/api/Hesaplamalar';

export function KidemForm() {
  const dispatch = useDispatch();
  const { kidemData, loading, error } = useSelector(state => state.hesaplama);

  const handleLoadKidem = async (yil: number, hazirlayanId: number) => {
    try {
      dispatch(loadKidemStart());
      const data = await getKidemHesapla(yil, hazirlayanId);
      dispatch(loadKidemSuccess(data));
    } catch (err) {
      dispatch(loadKidemError(err instanceof Error ? err.message : "Hata"));
    }
  };

  return <div>{/* Form UI */}</div>;
}
```

## 7. Custom Hooks

### 7.1 API Data Fetching Hooks

```typescript
// src/hooks/useKidemData.ts
import { useState, useEffect } from 'react';
import { getKidemHesapla } from '@/api/Hesaplamalar';

export function useKidemData(yil: number, hazirlayanId: number) {
  const [data, setData] = useState<KidemTazminatıBobi | null>(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    let mounted = true;

    const fetchData = async () => {
      try {
        setLoading(true);
        const result = await getKidemHesapla(yil, hazirlayanId);
        if (mounted) setData(result);
      } catch (err) {
        if (mounted) setError(err instanceof Error ? err.message : "Bilinmeyen hata");
      } finally {
        if (mounted) setLoading(false);
      }
    };

    fetchData();

    return () => {
      mounted = false; // Cleanup flag
    };
  }, [yil, hazirlayanId]);

  return { data, loading, error };
}
```

### 7.2 Hook Rules

- ✅ Custom hooks start with `use`
- ✅ Call hooks at the top level, not conditionally
- ✅ Use cleanup in `useEffect` (return unsubscribe/cleanup function)
- ✅ Include proper dependency arrays `[]`
- ❌ Don't call hooks in loops, conditions, or nested functions
- ❌ Don't use hooks in utility functions

## 9. Validation & Error Handling

### 9.1 Input Validation

```typescript
// src/utils/validation.ts
export function validateKidemGirisleri(data: KidemGirisi): string[] {
  const errors: string[] = [];

  if (!data.personelAdi?.trim()) {
    errors.push("Personel adı gerekli");
  }

  if (data.baslangicTarihi > data.bitisTarihi) {
    errors.push("Başlangıç tarihi bitiş tarihinden sonra olamaz");
  }

  if (data.maas <= 0) {
    errors.push("Maaş 0'dan büyük olmalıdır");
  }

  return errors;
}

// In component:
const errors = validateKidemGirisleri(formData);
if (errors.length > 0) {
  setValidationErrors(errors);
  return;
}
```

### 9.2 Error Handling Pattern

```typescript
// Consistent error handling across API calls
try {
  const result = await getKidemHesapla(yil, hazirlayanId);
  handleSuccess(result);
} catch (error) {
  const message = error instanceof Error 
    ? error.message 
    : "Bilinmeyen bir hata oluştu";
  
  console.error("❌ Hesaplama hatası:", message);
  
  // Show user-friendly toast/notification
  showError(`Hesaplama başarısız: ${message}`);
  
  // Optionally re-throw for parent handling
  // throw error;
}
```

### 9.3 Form-Level Validation

```tsx
'use client';

import { useState } from 'react';
import { Button } from "@/components/ui/button";
import { Input } from "@/components/ui/input";
import { Label } from "@/components/ui/label";

export function KidemForm() {
  const [validationErrors, setValidationErrors] = useState<Record<string, string>>({});

  const handleSubmit = async (e: React.FormEvent<HTMLFormElement>) => {
    e.preventDefault();
    
    const formData = new FormData(e.currentTarget);
    const data = Object.fromEntries(formData);

    // Validate
    const errors = validateKidemGirisleri(data as KidemGirisi);
    if (errors.length > 0) {
      setValidationErrors(errors.reduce((acc, err) => ({ ...acc, message: err }), {}));
      return;
    }

    // Submit
    try {
      await updateFormHazirlayanOnaylayan(yil, formKodu, data);
      showSuccess("Form başarıyla kaydedildi");
    } catch (error) {
      showError("Form kaydedilemedi");
    }
  };

  return (
    <form onSubmit={handleSubmit} className="space-y-4">
      <div className="space-y-2">
        <Label htmlFor="personelAdi">Personel Adı</Label>
        <Input id="personelAdi" name="personelAdi" />
        {validationErrors.personelAdi && (
          <p className="text-sm text-red-500">{validationErrors.personelAdi}</p>
        )}
      </div>
      <Button type="submit">Kaydet</Button>
    </form>
  );
}
```

## 15. Common Pitfalls & Solutions

### 15.1 Server Component Mistakes

❌ **Mistake:** Using `useState` in Server Components
```tsx
// DON'T DO THIS
export default async function Page() {
  const [count, setCount] = useState(0); // ❌ Won't compile
}
```

✅ **Solution:** Use Client Component
```tsx
'use client';

import { useState } from 'react';

export default function Page() {
  const [count, setCount] = useState(0); // ✅ Works
}
```

### 15.2 Async Props in Components

❌ **Mistake:** Returning Promise in component props without awaiting
```tsx
// Server Component
export default function Page() {
  return <ClientComponent data={fetchData()} />; // ❌ Passing Promise
}
```

✅ **Solution:** Await before passing
```tsx
// Server Component
export default async function Page() {
  const data = await fetchData();
  return <ClientComponent data={data} />; // ✅ Passing actual data
}
```

### 15.3 Client Component in Server Component Props

❌ **Mistake:** Trying to serialize Client Component through JSON
```tsx
// Server Component
export default function Page() {
  const ClientComp = dynamic(() => import('./Client'), { ssr: false });
  return <ClientComp />; // ❌ Won't work in Server Component
}
```

✅ **Solution:** Import Client Component directly
```tsx
// Server Component
import { ClientComp } from './Client';

export default function Page() {
  return <ClientComp />; // ✅ Works
}
```

### 15.4 Infinite Re-renders

❌ **Mistake:** Missing dependency array in useEffect
```tsx
'use client';

useEffect(() => {
  fetchData(); // Called on every render = infinite loop
}, []); // ❌ Forgot dependency array
```

✅ **Solution:** Always include dependencies
```tsx
'use client';

useEffect(() => {
  fetchData();
}, [yil, hazirlayanId]); // ✅ Specified dependencies
```
